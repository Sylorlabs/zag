# Zag driver support matrix

This table is generated by `tests/generate_driver_support_matrix.sh` and is
intentionally fail-closed: `planned` or `blocked` is not support, and a row is
promoted only by the complete release gate.

| Kernel series | Target | Shared core lowering | Userspace adapter | Kbuild handoff | Kernel module | QEMU boot/load/unload | Emulator | Physical devices |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| Linux 6.1 | x86_64 | supported | supported | supported | supported | supported | supported | unavailable |
| Linux 6.1 | arm64 | supported | supported | supported | supported | supported | supported | unavailable |
| Linux 6.1 | i686 | supported | supported | supported | supported | supported | supported | unavailable |
| Linux 6.6 | x86_64 | supported | supported | supported | supported | supported | supported | unavailable |
| Linux 6.6 | arm64 | supported | supported | supported | supported | supported | supported | unavailable |
| Linux 6.6 | i686 | supported | supported | supported | supported | supported | supported | unavailable |

The current release evidence provides the shared typed contract, generic
emulator model, versioned metadata, Kbuild handoff, and QEMU lifecycle for all
six rows. A row changes to `supported` only when the release gate has
executable evidence for every column that is being claimed. The QEMU rows
additionally require
`ZAG_DRIVER_LINUX_<series>_<target>_KERNEL`, matching initrd, two identical
module generations, and `ZAG_DRIVER_KBUILD_<series>_<target>`. macOS,
Windows, BSD, RISC-V, arbitrary Linux kernels, and physical-device
certification remain unavailable.
